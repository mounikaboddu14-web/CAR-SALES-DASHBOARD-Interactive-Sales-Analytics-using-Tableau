# 🚗 Car Sales Dashboard

An interactive **Car Sales Dashboard built using Tableau** to analyze and visualize car sales data. The dashboard provides a clear view of sales performance and helps identify important trends and business insights.

## 📊 Project Overview

The dashboard analyzes car sales data from **2020–2021** using Tableau. It includes key performance indicators and interactive visualizations for understanding sales across different dimensions.

### Key Features

- 📈 **YTD Total Sales**
- 💰 **YTD Average Price**
- 🚘 **YTD Cars Sold**
- 📊 **Year-over-Year (YoY) Growth**
- 📅 **Weekly Sales Trend**
- 🚙 **Sales by Body Style**
- 🎨 **Sales by Colour**
- 📍 **Sales by Dealer Region**
- 🏢 **Company-wise Sales Analysis**
- 🔍 Interactive filters for:
  - Date
  - Transmission
  - Body Style
  - Engine
  - Gender

## 🛠️ Technologies Used

- **Tableau Desktop**
- **CSV / Excel**
- Tableau Calculated Fields
- FIXED LOD Expressions
- Table Calculations
- Dual-Axis Charts
- Measure Names & Measure Values

## 📌 Key Insights

- **SUV** is the highest-selling body style.
- **Pale White** is the most popular car colour.
- **Austin** is the top-performing dealer region.
- **Chevrolet** leads the companies in total sales.
- **Cadillac** has the highest average selling price.
- Weekly sales show significant variations across the selected period.

## 🎯 Objective

The main objective is to transform raw car sales data into an **interactive business intelligence dashboard** that helps users analyze sales performance, identify trends, compare different categories, and support data-driven decision-making.
